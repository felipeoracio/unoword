# PDF fonts

DejaVu Serif, Sans and Sans Mono, including bold/italic variants, are bundled for
private PDF export. See [LICENSE.txt](LICENSE.txt) for the Bitstream Vera/DejaVu
font permissions and notices. These are PDF substitutions, not new editor font
choices. No runtime downloads are made. Coverage varies by script; do not claim
all Unicode/emoji support. Tests exercise Latin, Greek and Cyrillic extraction.
