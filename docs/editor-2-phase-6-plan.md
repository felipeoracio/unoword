# Editor 2.0 — Phase 6 plan

Phase 5 approved for production; Phase 6 authorized on a separate local branch.
Stop before Phase 7 and before releasing Phase 6 without review.

Retain the existing motion tokens, Tiptap/view, document schema, autosave, session
credit, project-switch contract and AI retrieval/usage gates. No backend, database,
new motion library or artificial waiting states.

- Give the newer grouped formatting/image/table menus native popover entry/exit
  feedback using the existing dropdown/exit tokens. Closed surfaces stop accepting
  input immediately; CSS display/overlay transitions are progressive enhancement.
- Add restrained entrances to Find/Outline, the selection toolbar, View menu and
  portaled statistics/print/shortcut dialogs. Leave native positioning and selection
  authoritative. No animation of authored paragraphs, image dimensions or counters.
- Extend color/border feedback and pressed-state chevrons to these controls, with
  immediate focus rings and complete reduced-motion overrides.
- Keep the existing Focus FLIP and project save-before-switch transitions. Cancel
  overlapping document cues at focus/project boundaries. Avoid duplicate reveals.
  Close hidden native menus on Focus entry and return keyboard input to the editor.
- Refine opening so each hydrated document receives one cue even when the paper
  element is retained. Do not replay on typing, saves, timers, AI or formatting.
  Input immediately cancels document opacity cues; no editor remount or cursor move.
- Give the existing truthful save-status indicator a subtle tone/halo transition.
  Never delay or manufacture Saved, offline, pending, failed or paused states.

Verify native menu reversal/closing, keyboard focus, text selection, undo and credit,
per-document opening, Focus Mode, slow/failed/offline saves, project switching,
responsive controls and live reduced-motion preference changes. Record preview
screenshots and a short synthetic-data interaction video. Use isolated fixtures;
production release verification is read-only. Broad final audits remain Phase 7.
